# Математика — понять каждый шаг

Статический учебный тренажёр по алгебре и геометрии.

- Геометрия: 13 тем, 131 раздел теории, 26 подробных разборов, 26 самостоятельных задач.
- Алгебра за первую четверть 8 класса: 10 тем, 3 подробных разбора и 5 самостоятельных заданий на каждую тему (30 разборов, 50 заданий).
- Проверка чисел, вариантов и алгебраических выражений; подсказки и раскрываемые решения.
- Равенство рациональных выражений проверяется символически с целыми коэффициентами BigInt, без выполнения пользовательского кода. ОДЗ проверяется отдельным полем.
- SVG-чертежи и графики, мобильная версия, локальное сохранение прогресса.

Теория изложена своими словами по учебникам «Геометрия. 7–9 классы», 2023 и Макарычев и др. «Алгебра. 8 класс», 2024. Пункты и страницы указаны в темах. Задачи составлены для тренажёра. Раздел алгебры соответствует главе I (пункты 1–8); точная граница четверти зависит от школьного планирования.

## Публикация на GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Все файлы сайта находятся в корне. Сборка и внешние зависимости не нужны.

Можно также открыть index.html локально. Прогресс хранится в браузере (прежний ключ и результаты геометрии сохранены) и не синхронизируется между устройствами или разными адресами сайта.
