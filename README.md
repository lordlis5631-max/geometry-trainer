# Геометрия — понять и доказать

Учебный тренажёр по геометрии за 7 класс и первой четверти 8 класса.

- 13 тем и 131 раздел теории.
- 26 задач с пошаговым разбором и объяснением доказательств.
- 26 самостоятельных задач с проверкой, подсказками и решениями.
- Чертежи SVG, мобильная версия, локальное сохранение прогресса.

Теория изложена своими словами по учебнику «Геометрия. 7–9 классы», базовый уровень, 2023. Пункты и страницы указаны в темах. Задачи составлены для тренажёра.

## Публикация на GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Все файлы сайта находятся в корне. Сборка и внешние зависимости не нужны.

Можно также открыть index.html локально. Прогресс хранится в браузере и не синхронизируется между устройствами или разными адресами сайта.
